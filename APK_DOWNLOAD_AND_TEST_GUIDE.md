## ❓ TROUBLESHOOTING

### **"APK won't download"**
Solution:
1. Try a different browser
2. Right-click download link → "Save as"
3. Use a different device
4. Wait 5 minutes and try again
5. Try backup links above

### **"APK won't install"**
Solution:
1. Go to Settings → Apps → Special app access
2. Find "Unknown sources" or "Install unknown apps"
3. Enable for browser app (where you downloaded APK)
4. Try installing again
5. Make sure Android version is 5.0+

### **"Can't create account"**
Solution:
1. Check internet connection (WiFi or mobile data)
2. Try different email address
3. Email might already exist - try login instead
4. Check email inbox for verification email

### **"Payment fails in app"**
Solution:
1. Use test card: 4111 1111 1111 1111
2. Use future expiry date: 12/25 or later
3. Use any 3-digit CVV
4. Check internet connection
5. Go slow - don't tap submit multiple times

### **"App crashes on launch"**
Solution:
1. Restart your phone
2. Uninstall and reinstall APK
3. Clear app cache (Settings → Apps → Marketplace → Clear Cache)
4. Try on different Android device
5. Report to me with these details:
   - Device name
   - Android version
   - What were you doing when it crashed
   - Any error message shown
